各課重點

第16課　曾參殺人　《戰國策》

詞語意思
曾子曾參，字子輿，春秋時魯國武城人，以孝順聞名，道德修養高尚，後世尊稱為「宗聖」
處居住、在（課本標註）
費地名，在當時魯國（課本標註）
同名族同名同姓
自若態度自然如常
有頃不久、一會兒
杼織布機上用來牽引緯線的梭子
逾翻越

課本隨堂練習答案：1. C　2. A　3. D　4. D

「予＝余＝吾」是「我」；「愚＝某＝僕」是自謙的說法（課本標註）。

成語「曾參殺人」：後比喻流言可畏或誣枉的災禍（課本標註）。「三人成虎」：比喻謠言惑眾；「人云亦云」：沒有主見（課本標註）。

曾母第一次、第二次聽到消息都「織自若」，第三次才「投杼逾牆而走」：謠言一再傳來，連最信任兒子的母親也會動搖。

第17課　鼠畫逼真　《獨醒雜志》

詞語意思
東安古縣名，在今湖南省境內
士人讀書人
善精通、擅長
軸量詞，用來計算卷軸裝裱成的書畫，相當於「幅」；後文的「軸」，都借代「圖畫」
邑令縣令
漫漫不經心、隨便
旦早晨
物色察看
逮等到、及（不是逮捕）
跳踉形容貓跳撞捕捉的樣子
然這樣，＝如此
逼真跟真的一樣（補充）

課本隨堂練習答案：1. C　2. D　3. B　4. A

省略的主詞（課本標註 S）：「逮舉軸」的主詞是縣令；「則跳踉逐之」的主詞是貓；「以試群貓」的主詞是縣令。

「軸在地，而貓蹲其旁；逮舉軸，則跳踉逐之」：從貓的反應，側面烘托出畫得逼真（課本隨堂練習 3）。

「屢懸屢墜」：一再掛上去，一再掉下來；「莫不然者」：沒有不這樣的。

第18課　嗜魚弗受　《韓非子》

詞語意思
公孫儀《史記》稱公儀休，春秋時代魯穆公的宰相；文中稱他「一國之相」（課本標註）
嗜喜愛
盡都（＝舉國：全國）
弟弟子
諫下對上規勸
唯正因為
下人遷就他人
枉私意歪曲
免被罷免
給供給
長長久
致贈送

課本隨堂練習答案：1. A　2. B　3. C　4. B

修辭「層遞」（課本標註）：受魚 → 下人之色 → 枉於法 → 免於相，一層一層推進，說明收下魚的後果。

公孫儀的想法：正因為愛吃魚，才不能收魚；一旦收了魚，就會被罷免，那時別人不一定再送魚，自己又供應不起。不收魚，才能長久自己供魚給自己。

第19課　兄弟爭雁　《賢類編》

詞語意思
昔從前
睹看見
翔飛翔
援拉
烹燒煮（＝煮）
舒雁行動遲緩的鵝
翔雁善於飛翔的鴻雁
燔燒、烤（＝烤）
訟公開爭論是非曲直
社伯古代二十五戶為一社；伯，長者
索尋找
凌升高
宜適合（補充）

課本隨堂練習答案：1. A　2. D　3. D　4. C

「舒雁烹宜，翔雁燔宜」＝舒雁宜烹、翔雁宜燔：鵝適合煮，鴻雁適合烤。

成語「當機立斷」：把握時機，立刻做出決定（課本標註）。

智慧諺語：「兄弟和氣金不換」、「打虎還需親兄弟」（見補充「成語與典故」）。

第20課　顧況戲白居易　《唐摭言》

詞語意思
白樂天唐朝名詩人白居易，字樂天，晚年信佛，自號香山居士，又號醉吟先生
舉考中舉人
謁拜見（ㄧㄝˋ）
顧況唐代詩人
謔開玩笑、戲弄
野火焚燒野草的大火
老夫老年男子的自稱
戲開玩笑、嘲弄

課本隨堂練習答案：1. B　2. A　3. D　4. A

顧況說「長安百物貴，居大不易」，是拿白居易名字裡的「居易」二字開玩笑；讀到「野火燒不盡，春風吹又生」後，才改口稱讚，說「居天下有何難」。

「有句如此，居天下有何難！」是激問，意思是「一點也不難」。

「野火燒不盡，春風吹又生」：常用來比喻問題若沒有從根本解決，過一段時間可能又會再發生（課本隨堂練習 3）。「防患未然」是在禍患沒有發生之前就加以防備（課本標註）。

轉品（詞性轉換）

詞語詞性轉變與意思例句（出處）

轉品：詞語臨時轉用成另一種詞性。

借代（第17課）

詞語借代的意思例句（出處）
軸以裱成卷軸的畫，借代「圖畫」「軸」在地；逮舉「軸」（第17課，注釋④）

借代：不直接說出本來的人事物，改用和它關係密切的名稱來代替。

修辭

修辭說明例句（出處）
層遞依照程度、範圍、事情的發展，一層一層推進夫即受魚，必有下人之色；有下人之色，則枉於法；枉於法，則免於相（第18課，課本標註）
頂真前一句的結尾，成為下一句的開頭有下人之色，則枉於法；枉於法，則免於相（第18課，補充）
側面烘托不直接描寫，從旁人或旁物的反應，襯托出主要的人事物軸在地，而貓蹲其旁；逮舉軸，則跳踉逐之（第17課，課本隨堂練習 3）
提問心中有疑而問，答案在下文夫子嗜魚而不受者，何也？（第18課，補充）
激問答案在問題的反面，用來加強語氣有句如此，居天下有何難！（第20課，補充）
雙關一句話同時含有兩層意思居大不易：表面說長安物價貴，實則拿「居易」的名字開玩笑（第20課，補充）

虛字練習（課文中的虛字）

  1. 「吾子不殺人」的「吾」，與下列哪一個字的意思「不同」？
    予＝余＝吾＝僕，都是「我」（僕多用於自謙）；汝是「你」。
  2. 下列哪一個字，是用來表示「自謙」的自稱？
    愚＝某＝僕，是自謙的說法；吾、予、余只是一般的「我」。
  3. 「曾子之母曰」的「之」，意思是？
    曾子之母＝曾子的母親，「之」是助詞，相當於「的」。
  4. 「令怪之」的「之」，指的是什麼？
    縣令覺得奇怪的，是畫軸一再掉落在地上這件事（課本標註）。
  5. 下列各句「之」所指的對象，何者「正確」？
    過之＝經過掛畫的地方；射之＝射雁；獻之＝獻給公孫儀；謔之＝戲弄白居易。
  6. 「竟鬥而訟於社伯」的「於」，意思是？
    訟於社伯＝向社伯訴訟，請他評理。
  7. 「則免於相」的「於」，意思是？
    免於相＝被罷免宰相（注釋⑨）；「於」放在動詞後面，表示被動。
  8. 下列哪一句的「於」，意思是「在」？
    漫懸於壁＝隨便掛在牆壁上。苛政猛於虎（比）、勿施於人（給）、免於相（被）。
  9. 「以歌詩謁顧況」的「以」，意思是？
    以歌詩＝用詩歌；謁＝拜見（課本標註「用」）。
  10. 「一國盡爭買魚而獻之」的「盡」，意思是？
    盡：都（注釋③），副詞。一國盡＝舉國、全國都。
  11. 下列「舉」字的意思，何者「配對錯誤」？
    逮舉軸的「舉」是拿起、提起；考中舉人是「白樂天初舉」。
  12. 「軸必墜地，屢懸屢墜」的「屢」，意思是？
    屢懸屢墜＝一再掛上去，一再掉下來（課本標註「每每、總是」）。
  13. 「漫懸於壁」的「漫」，意思是？
    漫：漫不經心、隨便（注釋⑥），副詞。
  14. 「夫唯嗜魚，故不受也」的「唯」與「故」，意思依序是？
    唯：正因為（注釋⑥）；故：所以，連詞。
  15. 「夫即受魚，必有下人之色」的「即」，意思是？
    即：假如，連詞。夫即受魚＝假如收下了魚。
  16. 下列哪一個詞，「不能」用來表示「等到」？
    及、逮、比都是「等到」；昔＝從前。
  17. 「舒雁烹宜，翔雁燔宜」的意思是？
    舒雁＝行動遲緩的鵝；翔雁＝善於飛翔的鴻雁；烹＝煮；燔＝烤；宜＝適合。
  18. 「有頃焉，人又曰」的「有頃」與「焉」，意思依序是？
    有頃：不久、一會兒（注釋⑤）；焉：語末助詞，不必翻譯。
  19. 「老夫前言戲之耳」的「戲」與「耳」，意思依序是？
    戲：開玩笑、嘲弄（注釋⑧）；耳：語末助詞，罷了。

成語、修辭與文學常識

  1. 「三人成虎」比喻什麼？
    三人成虎：比喻謠言惑眾（課本標註）。曾參殺人的故事，說的就是同樣的道理。
  2. 「夫即受魚，必有下人之色；有下人之色，則枉於法；枉於法，則免於相。」運用了哪一種修辭？
    受魚 → 下人之色 → 枉於法 → 免於相，一層一層推進，是層遞（課本標註）。
  3. 下列成語與意義的配對，何者「正確」？
    民胞物與＝博愛；任勞任怨＝不怕辛勞和埋怨；廉潔奉公＝為官清廉、一心為公。
  4. 「香餌之下必有懸魚」與下列哪一句話的意思最接近？
    有好處可圖，就一定有人願意去做（課本標註：＝重賞之下必有勇夫）。
  5. 「又送王孫去，萋萋滿別情」的「萋萋」，形容的是？
    離離、蔚蔚、萋萋、扶疏，都是形容草木茂盛的樣子（簡報）。
  6. 「又送王孫去，萋萋滿別情」化用《楚辭》「王孫游兮不歸，春草生兮萋萋」，詩中以春草寫出什麼情感？
    以春草不斷蔓生，比喻離愁不斷，是寫「離情」（簡報）。

第16課　曾參殺人　《戰國策》

  1. 第一個人來告訴曾母「曾參殺人」時，曾母的反應是？
    「曾子之母曰：吾子不殺人。織自若也。」
  2. 費地真正殺了人的，是誰？
    「費人有與曾子同名族者而殺人」；同名族＝同名同姓。
  3. 曾母前兩次「織自若」，第三次卻「投杼逾牆而走」，這種轉變說明了什麼？
    曾母的態度改變，不是因為事實不同，而是因為同樣的話聽了一遍又一遍。
  4. 這則故事最能提醒我們，面對傳言時應該怎麼做？
    故事的寓意：流言可畏，謠言傳得多了，連堅定的信念也會被動搖。

第17課　鼠畫逼真　《獨醒雜志》

  1. 縣令一開始把鼠畫「漫懸於壁」，可以看出他當時對這幅畫的態度是？
    漫：隨便（注釋⑥）；「令初不知愛」，也就是一開始不懂得珍惜。
  2. 縣令為什麼會「怪之」？
    「旦而過之，軸必墜地，屢懸屢墜」。
  3. 縣令發現畫軸掉在地上、貓蹲在旁邊，等他舉起畫軸時，貓有什麼反應？
    「逮舉軸，則跳踉逐之」。
  4. 縣令用這幅畫試了其他的貓，「莫不然者」，最後得到什麼結論？
    「於是始知其畫為逼真」。

第18課　嗜魚弗受　《韓非子》

  1. 「夫即受魚，必有下人之色」這句話的意思是？
    下人＝遷就他人（注釋⑦）；色＝神色、態度。
  2. 公孫儀認為接受別人送的魚，最後會有什麼結果？
    下人之色 → 枉於法 → 免於相（層遞）。
  3. 公孫儀說「我又不能自給魚」，意思是？
    免於相，雖嗜魚，此不必能致我魚，我又不能自給魚：被罷免後，送魚的人不一定再送，自己又供應不起。
  4. 從公孫儀不受魚的做法，最能看出他是怎樣的人？
    他不收魚，是看得長遠，也不願為了魚而枉法。

第19課　兄弟爭雁　《賢類編》

  1. 哥哥看見雁飛過，說「獲則烹」，意思是？
    獲：射到；則：就；烹：煮。
  2. 弟弟為什麼主張「翔雁燔宜」？
    翔雁＝善於飛翔的鴻雁；燔＝烤；宜＝適合。
  3. 社伯處理兄弟爭執的辦法是？
    「社伯請剖雁，烹、燔半焉」。
  4. 「已而索雁，則凌空遠矣」，這句話帶給我們什麼啟示？
    兄弟爭得太久，雁早就飛遠了。

第20課　顧況戲白居易　《唐摭言》

  1. 白居易帶著詩作去拜見顧況，是為了什麼？
    當時文人有一種風氣：把自己的作品送給有名望的人過目，請他們批評指教。
  2. 顧況讀到〈賦得原上草送友人〉的哪兩句詩，而改變了對白居易的看法？
    文中「及讀至……詩曰：野火燒不盡，春風吹又生」，顧況才嘆道：「有句如此，居天下有何難！」
  3. 顧況說「老夫前言戲之耳」，是想表達什麼？
    戲：開玩笑（注釋⑧）；耳：罷了。前言戲之耳＝先前說的只是玩笑話。
  4. 「有句如此，居天下有何難！」這句話的意思是？
    這是激問，答案在問題的反面：一點也不難。
